# Модель движения Random Walk
1. Генерация случайного направления
  Угол движения генерируется равномерно распределенным в диапазоне [0, 2π]:
2. Длина шага
  Длина каждого шага зависит от текущей скорости и случайного коэффициента:
  step = random() × currentSpeed
  где random() ∼ U(0, 1)
3. Обновление координат
  Новые координаты вычисляются по формулам:
  x_{t+1} = x_t + step × cos(θ)
  y_{t+1} = y_t + step × sin(θ)
